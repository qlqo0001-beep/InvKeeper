# InvKeeper v1.4.1 릴리즈 노트

> 출시일: 2026-08-11
> 주요 변경: **무덤 GUI/도굴/히스토리 버그 수정**

---

## 🐛 버그 수정

### 무덤 GUI — "모두 회수"
- "모두 회수" 버튼 클릭 시 장비/왼손/인벤토리 36칸/경험치를 전량 회수한 뒤 **GUI가 자동으로 닫히도록 수정**. 기존에는 회수 후에도 창이 열려 있어 아이템이 남아 보이다가 클릭하면 사라지는 것처럼 보이는 문제가 있었음.

### 도굴 취소
- 도굴이 진행 중인 무덤을 **주인이 다시 열면 도굴이 즉시 취소**되도록 수정. 도굴자에게 취소 안내 메시지를 전송하고, 무덤 상태를 `ACTIVE`로 되돌림. 주인이 관리자(op) 권한을 함께 가진 경우에도 도굴 취소가 우선 적용됨.

### 무덤 GUI 레이아웃
- 맨 윗줄의 미사용 칸(장비/왼손/경험치병이 채워지지 않은 슬롯)을 **회색 색유리 판**으로 채우고, 마우스를 올려도 이름이 표시되지 않도록 빈 이름 처리.
- "모두 회수" 버튼은 맨 아랫줄 중앙(슬롯 49)에 배치하고, 양옆은 동일하게 이름 없는 회색 색유리 판으로 채움.

### 무덤 영속화(서버 재시작)
- 무덤이 존재하는 상태에서 서버가 재시작돼도 **무덤 데이터(위치/소유자/내용물/상태/도굴 세션)가 디스크에서 정상 복원**되도록 수정. 기존에는 통 블록만 남고 무덤 데이터가 사라지는 불일치가 있었음.
- 청크 로드 시 무덤 블록 무결성을 검사해 블록이 사라졌으면 자동으로 재배치.

### 히스토리(어드민) — 상호작용 불능 수정
- `/invkeeper grave history <player>`로 연 히스토리 GUI에서 **좌클릭(텔레포트)/우클릭(가상 GUI 열기)/페이지 이동이 전혀 반응하지 않던 문제**를 수정. 원인은 명령어 실행 시 항목을 채우는 인스턴스와, 클릭을 처리하는 인스턴스가 서로 다른 캐시를 참조하던 버그였음.
- **좌클릭 = 해당 무덤 위치로 텔레포트**, **우클릭 = 사망 시점 원본 아이템이 담긴 가상 GUI 열기**로 동작을 명확히 분리(기존에는 우클릭 시 텔레포트와 GUI 오픈이 뒤섞여 있었음).
- 히스토리 가상 GUI는 회수됨/도굴됨/미회수 **어떤 상태의 무덤이라도** 열람 가능하며, 안의 아이템을 어드민이 개별/전량 회수 가능(회수 결과는 히스토리 기록에 즉시 반영).

### 히스토리 색유리 상태 표시
- 히스토리 목록의 색유리 판이 회수 상태를 정확히 반영하도록 보강: **회수됨(노랑)** / **도굴됨(빨강)** / **미회수(연두)**. 도굴이 완료됐지만 도굴자가 아직 아이템을 가져가지 않은 무덤도 "도굴됨(빨강)"으로 표시되도록 판정 기준을 보완.
