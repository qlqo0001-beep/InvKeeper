## 주요 변경사항

### 버그 수정

#### 스택형 각인 사망 시 보호 및 로어 갱신 버그 수정 (v1.3.1 → v1.3.2 재수정 → v1.3.3 안정화)

**문제 1: 스택 1회 각인 아이템이 사망 시 드랍됨**
- **원인**: `PlayerDeathListener.onPlayerDeath()`에서 스택 차감(`decrementStacks()`)을 보호 확인 전에 수행하여, 스택이 1→0으로 줄어들고 각인이 제거된 후 드랍됨
- **수정**: 3단계 처리로 분리
  1. TIME 만료 정리 (드랍 전)
  2. 드랍 계산 (STACK은 아직 각인 상태 유지 → 보호됨)
  3. STACK 소모 (드랍 후) + 로어 갱신
- **결과**: 스택 1회 각인 아이템은 사망 시 보호되어 드랍되지 않음

**문제 2: 스택 차감 후 로어 텍스트가 갱신되지 않음**
- **원인**: `SoulbindManager.decrementStacks()` 메서드에서 PDC 값만 차감하고 `updateLore()`를 호출하지 않아 플레이어가 보는 각인 횟수가 실제와 다름
- **수정**: `decrementStacks()` 호출 후 `updateLore()`를 호출하여 로어 텍스트를 실제 스택 수에 맞게 갱신
- **결과**: 사망 후 각인 횟수가 로어에 정확히 반영됨 (예: 2회 → 1회로 표시)

### 개선 사항

#### 각인 아이템 픽업 차단 메시지 쿨다운 추가

**문제**: 다른 플레이어의 각인 아이템을 주우려고 할 때, 메시지가 매 틱마다(초당 20회) 표시되어 채팅이 도배됨

**수정**:
- `config.yml`에 `soulbind-pickup-message-cooldown-seconds` 설정 추가 (기본값: 5초)
- `SoulbindPickupListener`에 플레이어별 메시지 쿨다운 로직 추가
- 설정값으로 0을 입력하면 쿨다운 없음 (기존 동작)
- 양수 값을 입력하면 해당 초마다 메시지 표시

**메시지 개선**:
- `{item_name}` 플레이스홀더 추가로 아이템 이름 표시
- 예: "다이아몬드 검은(는) 플레이어명의 각인 아이템입니다. 획득할 수 없습니다."

## 마이그레이션 가이드

### 기존 사용자
- 기존 `config.yml`, `items.yml`, `messages.yml`을 그대로 사용 가능
- 설정 파일 변경 없이 자동으로 버그 수정 및 개선 사항 적용

### 새로운 설정
```yaml
# config.yml에 추가된 설정
soulbind-pickup-message-cooldown-seconds: 5  # 기본값 5초, 0이면 쿨다운 없음
```

### 주의사항
- 스택형 각인 아이템을 소지한 상태로 사망 시, 각인 횟수가 1회 차감되고 로어가 갱신됩니다
- 스택이 0이 된 아이템은 각인이 완전히 제거됩니다
- 각인 아이템 픽업 차단 메시지가 5초에 한 번만 표시됩니다 (설정으로 조정 가능)
