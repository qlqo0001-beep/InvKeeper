# InvKeeper v1.4.4 릴리즈 노트

> 출시일: 2026-09-27
> 주요 변경: **오프라인 중 시간형 보호 종료 시 재접속 알림 추가**

---

## ✨ 기능 개선

### 오프라인 중 보호 종료 알림
- 시간형 보호는 접속 여부와 관계없이 실제 시각 기준으로 줄어들기 때문에, 접속하지 않은 동안 보호가 종료되면 플레이어가 이를 모른 채 플레이할 수 있었음.
- 이제 다음 접속 시 `timed-expired-offline` 메시지를 1회 전송. `{expired_at}`으로 종료 시각 표시 가능 (`config.yml`의 `timezone` 기준, 예: `2026-09-27 18:30`).
- `""`로 비워두면 전송하지 않음.

```yaml
timed-expired-offline: "&c자리를 비운 사이 인벤토리 보호가 종료되었습니다. &8(종료: {expired_at}) &7사망 시 아이템을 잃을 수 있으니 주의하세요."
```

### 종료 알림 문구 변경
- 접속 중 종료 알림(`timed-expired`) 기본 문구에 사망 시 아이템 손실 경고 추가.

```yaml
timed-expired: "&c인벤토리 보호가 종료되었습니다. &7이제부터 사망 시 아이템을 잃을 수 있습니다."
```

### 기타
- 종료 알림 전송 후 만료된 보호 정보를 정리하여 같은 알림이 중복 전송되지 않도록 처리.

---

## 🔁 업데이트 시 참고
- 기존 서버의 `messages.yml`은 자동으로 갱신되지 않음. 키가 없으면 위 기본 문구로 동작하며, 문구를 변경하려면 키를 직접 추가 후 `/invkeeper reload`.
- 업데이트 전에 이미 보호가 종료된 플레이어도 업데이트 후 첫 접속 시 종료 알림을 1회 받음.
