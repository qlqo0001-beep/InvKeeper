# InvKeeper

> Minecraft Paper 서버를 위한 **인벤토리 보호 및 영혼각인(Soulbind) 플러그인**

InvKeeper는 플레이어가 사망했을 때 인벤토리와 경험치의 드롭을 **월드**, **권한**, **보호 아이템** 설정에 따라 세밀하게 제어할 수 있는 Paper 플러그인입니다.

단순히 아이템을 보존하는 기능뿐만 아니라, **보호권**, **시간형 보호**, **영혼각인(Soulbind)** 시스템을 제공하여 서버 운영에 필요한 다양한 보호 기능을 지원합니다.

---

# 주요 기능

## 인벤토리 및 경험치 보호

* `keepInventory` 게임룰을 항상 `false`로 유지하여 인벤토리 복제 버그 방지
* 월드별 인벤토리 및 경험치 드롭 비율 설정
* 권한 우선순위에 따른 드롭 규칙 적용
* 메인 인벤토리, 핫바, 방어구, 보조 손을 포함한 **41칸 전체 인벤토리**에서 랜덤으로 아이템 드롭
* 실제 경험치 총량을 기준으로 설정한 비율만큼만 경험치 드롭

## 보호권 시스템

### 소모형 보호권

* 인벤토리에 소지하고 있으면 사망 시 자동으로 사용
* 사용 후 보호권 1개 차감
* 인벤토리와 경험치를 보호

### 시간형 보호권

* 우클릭으로 활성화
* 설정한 시간 동안 사망 보호 효과 유지
* 남은 시간이 5분, 1분일 때 자동 알림

## 영혼각인(Soulbind)

* 아이템에 소유자 정보를 저장
* 만료 시간이 있는 각인 또는 영구 각인 지원
* 소유자만 아이템을 획득하거나 이동 가능
* 타인의 각인 아이템 획득 차단
* Shift 클릭을 이용한 우회 이동 차단
* 호퍼, 드로퍼 등 자동 이동 차단
* 각인석을 이용한 드래그 앤 드롭 방식의 각인 및 해제
* 관리자 명령어 제공
* 권한을 통한 각인 우회 가능

## MMOItems 연동

* MMOItems 아이템 인식
* LiveMMOItem / NBTItem API 지원
* 다양한 MMOItems 버전과 호환

## 기타 기능

* `/invkeeper status` 명령어 제공
* 현재 적용 중인 드롭 규칙 확인
* 현재 보호 상태 확인
* 명령어 자동완성(Tab Complete) 지원

---

# 설치

1. 프로젝트를 빌드합니다.

```bash
mvn clean package
```

2. 생성된 `InvKeeper.jar`를 서버의 `plugins` 폴더에 넣습니다.

3. 서버를 실행하면 기본 설정 파일이 자동으로 생성됩니다.

```
plugins/
└── InvKeeper/
    └── config.yml
```

---

# 설정

모든 설정은 `config.yml`에서 관리합니다.

## keepInventory 설정

```yaml
force-keep-inventory-false: true
```

활성화하면 모든 월드의 `keepInventory` 게임룰을 항상 `false`로 유지합니다.

---

## 월드별 드롭 규칙

```yaml
rules:
  world:
```

월드마다 인벤토리와 경험치의 드롭 비율을 개별적으로 설정할 수 있습니다.

---

## 권한별 드롭 규칙

```yaml
rules:
  permissions:
```

권한 우선순위를 기준으로 드롭 비율을 다르게 적용할 수 있습니다.

예를 들어

* VIP
* 후원자
* 관리자

등급별로 서로 다른 보호 규칙을 적용할 수 있습니다.

---

## 보호 아이템

모든 보호 아이템은 `protection-items`에서 관리합니다.

각 아이템은 **고유 Key**를 가지며 다음과 같은 설정을 사용할 수 있습니다.

* 바닐라 아이템
* MMOItems 아이템
* 소모형 보호권
* 시간형 보호권
* 영혼각인석
* 영혼각인 해제석

### 주요 설정

| 옵션                          | 설명                      |
| --------------------------- | ----------------------- |
| `kind`                      | `consumable` 또는 `timed` |
| `use-type`                  | `vanilla` 또는 `mmoitems` |
| `duration-minutes`          | 시간형 보호권 지속 시간           |
| `soulbind.enabled`          | 자동 각인 활성화               |
| `soulbind.tool`             | 각인석 여부                  |
| `soulbind.duration-minutes` | 각인 유지 시간                |
| `soulbind.infinite`         | 영구 각인 여부                |
| `soulbind.unbind`           | 각인 해제석 여부               |

messages:

# 명령어

| 명령어                                           | 설명                            | 권한                |
| --------------------------------------------- | ----------------------------- | ----------------- |
| `/invkeeper reload`                           | 설정 파일을 다시 불러옵니다.              | `invkeeper.admin` |
| `/invkeeper give <플레이어> <아이템 키> [수량]`         | 보호 아이템을 지급합니다.                | `invkeeper.admin` |
| `/invkeeper status`                           | 현재 적용 중인 드롭 규칙과 보호 상태를 확인합니다. | 기본                |
| `/invkeeper soulbind unbind <플레이어> [슬롯\|all]` | 지정한 슬롯 또는 모든 영혼각인을 해제합니다.     | `invkeeper.admin` |
| `/invkeeper soulbind inspect <플레이어>`          | 플레이어의 영혼각인 아이템 목록을 확인합니다.     | `invkeeper.admin` |

## 명령어 별칭

```
/ik
```

`/ik`는 `/invkeeper`의 축약 명령어입니다.

# 권한

| 권한                          | 설명                       | 기본값   |
| --------------------------- | ------------------------ | ----- |
| `invkeeper.admin`           | 플러그인 관리 권한               | OP    |
| `invkeeper.drop.donor`      | 후원자 드롭 규칙 적용             | false |
| `invkeeper.drop.vip`        | VIP 드롭 규칙 적용             | false |
| `invkeeper.drop.admin`      | 관리자 드롭 규칙 적용             | false |
| `invkeeper.soulbind.bypass` | 다른 플레이어의 영혼각인 제한을 무시합니다. | false |
| `invkeeper.soulbind.give`   | 영혼각인 아이템 지급 권한           | false |

# 영혼각인(Soulbind)

영혼각인은 아이템에 **소유자 정보와 만료 시간**을 저장하여 지정한 플레이어만 사용할 수 있도록 만드는 시스템입니다.

아이템 정보는 **PersistentDataContainer(PDC)** 에 저장되므로 서버를 재시작해도 유지됩니다.

---

## 영구 각인

만료 시간이 `-1`인 경우 영구 각인으로 처리됩니다.

영구 각인은 시간이 지나도 해제되지 않습니다.

---

## 기간제 각인

각인석에 설정된 시간이 지나면 자동으로 만료됩니다.

만료 이후에는 일반 아이템처럼 사용할 수 있습니다.

---

# 영혼각인 적용 방법

## 1. 자동 각인

설정에서 자동 각인이 활성화된 보호 아이템은

* 지급
* 획득

시 자동으로 영혼각인이 적용됩니다.

---

## 2. 각인석 사용

각인석을 이용하여 원하는 아이템에 영혼각인을 적용할 수 있습니다.

### 사용 방법

1. 각인석을 커서에 듭니다.
2. 각인할 아이템 위로 이동합니다.
3. 드래그 앤 드롭하여 적용합니다.

성공하면

* 각인석이 1개 소모됩니다.
* 대상 아이템에 영혼각인이 적용됩니다.

---

## 3. 각인 연장

이미 각인된 아이템에도 각인석을 사용할 수 있습니다.

* 기간제 → 남은 시간 연장
* 영구 각인 → 그대로 유지

---

# 영혼각인 해제

## 각인 해제석

각인 해제석을 이용하여 영혼각인을 제거할 수 있습니다.

사용 방법은 각인석과 동일합니다.

---

## 관리자 명령어

```
/invkeeper soulbind unbind <플레이어>
```

또는

```
/invkeeper soulbind unbind <플레이어> all
```

관리자는 원하는 슬롯 또는 모든 영혼각인을 제거할 수 있습니다.

---

# 영혼각인 조회

관리자는 다음 명령어로 플레이어의 영혼각인 아이템을 확인할 수 있습니다.

```
/invkeeper soulbind inspect <플레이어>
```

각 슬롯의

* 아이템
* 소유자
* 남은 시간

정보를 확인할 수 있습니다.

---

# 제한 사항

영혼각인이 적용된 아이템에는 다음과 같은 제한이 적용됩니다.

### 아이템 획득

소유자가 아닌 플레이어는 아이템을 획득할 수 없습니다.

---

### 인벤토리 이동

다른 플레이어의 각인 아이템은 인벤토리에서 이동할 수 없습니다.

우회 이동을 시도하는 경우에도 차단됩니다.

---

### 자동 이동

다음과 같은 자동 이동은 모두 차단됩니다.

* 호퍼
* 드로퍼
* 상자 달린 광산수레
* 기타 자동 아이템 이동 장치

---

### 사망

플레이어가 사망하더라도 영혼각인이 적용된 아이템은 드롭되지 않습니다.

---

# 우회 권한

다음 권한을 가진 플레이어는 모든 영혼각인 제한을 무시할 수 있습니다.

```
invkeeper.soulbind.bypass
```

# 프로젝트 특징

InvKeeper는 단순히 `keepInventory`를 대체하는 플러그인이 아닙니다.

사망 시 아이템 및 경험치 보호를 보다 유연하게 관리할 수 있도록 설계되었으며, 다양한 서버 환경에 맞춰 세부적인 설정이 가능합니다.

### ✔ 월드별 드롭 규칙

월드마다 서로 다른 인벤토리 및 경험치 드롭 비율을 설정할 수 있습니다.

### ✔ 권한별 드롭 규칙

권한 우선순위를 이용하여 플레이어 그룹마다 서로 다른 보호 규칙을 적용할 수 있습니다.

### ✔ 다양한 보호 아이템

* 소모형 보호권
* 시간형 보호권
* 영혼각인석
* 영혼각인 해제석

등 다양한 형태의 보호 아이템을 설정할 수 있습니다.

### ✔ 높은 MMOItems 호환성

MMOItems 버전에 최대한 영향을 받지 않도록 구현되어 있으며, 다양한 버전에서 사용할 수 있도록 설계되었습니다.

### ✔ 아이템 자체에 저장되는 영혼각인

영혼각인 정보는 아이템의 `PersistentDataContainer(PDC)`에 저장됩니다.

따라서 서버를 재시작하거나 아이템을 이동해도 각인 정보가 유지됩니다.
